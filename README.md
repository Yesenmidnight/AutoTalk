# AutoTalk · 《不问凡尘》对话助手

一个极简的 Windows 桌面挂件：快捷键截取游戏对话 → 本地 OCR 识别 → AI 分析 NPC 性格与意图 → 给出三条一键复制的推荐回复，帮你把对话当"解谜题"来推进好感度。

## 工作原理

1. 启动后先点「选游戏窗口」，从系统窗口列表中指定游戏窗口（支持任意显示器，含副屏）
2. 在冻结的游戏窗口画面上「框选对话区」，保存的是**相对游戏窗口**的坐标
3. 按快捷键（默认 `Ctrl+Alt+T`）时，程序实时定位游戏窗口位置，截取其中的对话区域
4. 本地 OCR（RapidOCR，离线运行）识别文本，可手动修正错字
5. 将当前对话 + 最近几轮快照发送到你配置的大模型 API（OpenAI 兼容）
6. 挂件展示 NPC 分析、对话意图和三条风格迥异的推荐回复，**点击回复行即复制**

纯截屏方案：不读写游戏内存、不抓封包，不干预游戏进程。由于坐标相对游戏窗口，移动窗口、拖到别的显示器都不影响抓取。

## 安装

- Windows 10/11，Python 3.9+（64 位）
- 安装依赖：`py -3 -m pip install -r requirements.txt`
- 启动：`py -3 main.py`（或双击 `启动AutoTalk.bat`）

## 配置 AI

点挂件上的「设置」，填入 API 地址 / API Key / 模型名（地址可直接从下拉框选）。

**注意：API 地址必须与 Key 的类型匹配，否则报 401：**

| Key 类型 | API 地址 | 模型示例 |
| --- | --- | --- |
| 智谱 Coding Plan（订阅套餐） | `https://open.bigmodel.cn/api/coding/paas/v4` | `glm-5.3-flash`、`glm-4.6` |
| 智谱开放平台（按量付费） | `https://open.bigmodel.cn/api/paas/v4` | 以官网模型列表为准 |
| DeepSeek | `https://api.deepseek.com` | `deepseek-chat` |
| Kimi | `https://api.moonshot.cn/v1` | 以官网为准 |
| OpenAI | `https://api.openai.com/v1` | 以官网为准 |

## 使用流程

1. 游戏以窗口化或无边框模式运行，点挂件「选游戏窗口」，在列表中选定游戏（双击即可）
2. 随后会自动弹出游戏窗口的冻结画面，拖动框住对话窗口区域（之后可随时点「框选对话区」重选）
3. 对话时按 `Ctrl+Alt+T`（或点「抓取分析」）
4. 在 AI 建议区点击想要的回复行 → 自动复制 → 粘贴回游戏
5. 「自动·开」：每 N 秒自动 OCR 一次，对话内容变化时自动重新分析，无需按键
6. 识别文本框可手动修正错字，再点「重新分析」

## 常见问题

- **识别不到文字**：确认框选覆盖对话文本；对话区域不要被本挂件或其他窗口遮挡（截屏是截"屏幕所见"）。
- **列表里找不到游戏窗口**：独占全屏模式没有标准窗口句柄，请把游戏切换为"窗口化"或"无边框窗口"。
- **游戏窗口被移动/换显示器**：无需任何操作，坐标相对窗口，抓取时自动重新定位。
- **游戏窗口尺寸变了**（如改分辨率）：对话区域可能错位，重新点「框选对话区」即可。
- **401 令牌已过期或验证不正确**：Key 与 API 地址不匹配（Coding Plan 订阅 Key 用 `/api/coding/paas/v4`，按量付费 Key 用 `/api/paas/v4`），或 Key 本身失效。若换地址后仍 401，请到开放平台控制台**重新生成 API Key** 并完整复制（注意别少复制尾巴）。
- **快捷键没反应**：请到「设置」里点「录入」直接按下组合键（支持 `Ctrl+Alt+T`、`F8`、`` Ctrl+` `` 等；中文输入法下打出的 `·` 会自动识别为反引号 `` ` ``）。若游戏以管理员身份运行，AutoTalk 也需右键"以管理员身份运行"，否则快捷键在游戏内无效。
- **识别不准**：区域框大一点、调大游戏内字体；区域过窄时程序会自动 2 倍放大再识别。
- **首次 OCR 慢**：模型加载需几秒，属正常；之后单次识别通常几百毫秒。

## 文件说明

- `config.json`：全部配置（API、快捷键、区域坐标）。首次运行可直接在软件「设置」中填入并保存自动生成，或参考 `config.example.json`。注意 API Key 仅保存在本机，请勿上传至公开代码库。
- `config.example.json`：配置文件模板参考。
- `captures/`：在设置里开启"保存每次截图"后，每次抓取的截图会存档，便于排查识别问题。
- `scripts/selftest.py`：离线自检脚本，生成模拟对话图验证 OCR 是否正常。

## 隐私提示
